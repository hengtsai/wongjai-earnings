## 2. 🔍 五大核心洞察與法說會直擊

<div class="sb">
<h3>🎯 洞察一：Azure 40% 優於財測，需求仍大於供給</h3>
<p>Azure 年增 40%（固定匯率 39%），高於財測，財務長 Amy Hood 說主要來自最大客戶的核心基礎設施業務，Azure AI 服務大致符合公司自己的預估。她說<b>「即使上線了更多產能，各類工作負載的需求仍超過供給」</b>，並預告<b>「至少到財年底都會產能受限」</b>。Q2 Azure 財測約 37%（固定匯率）。</p>
</div>

<div class="sb">
<h3>🎯 洞察二：OpenAI 新協議，追加 2,500 億 Azure 承諾</h3>
<p>財報前一天，Microsoft 與 OpenAI 簽下新的正式協議。執行長 Satya Nadella 說投資已約<b>「翻了 10 倍」</b>，OpenAI 追加承諾採購 2,500 億美元 Azure 服務；營收分成、IP 與 API 獨家延續到 AGI 或 2030 年，模型與產品 IP 權利延長到 2032 年。Hood 強調 Q1 數字不受新協議影響，之後財測會排除 OpenAI 投資損益。</p>
</div>

<div class="sb">
<h3>🎯 洞察三：RPO 3,920 億，商業新簽約翻倍</h3>
<p>商業新簽約年增 112%，大幅高於公司預估，來自 OpenAI 的 Azure 承諾與億元級合約增加；這還不含追加的 2,500 億。商業 RPO 3,920 億、年增 51%，兩年內近乎翻倍，加權平均存續期間仍約 2 年。Nadella 說今年 AI 總產能將增加逾 80%，兩年內資料中心規模約翻倍。</p>
</div>

<div class="sb">
<h3>🎯 洞察四：Copilot 擴散，個人生產力部門營益率升到 62%</h3>
<p>Nadella 說 AI 功能每月活躍用戶 9 億，自家 Copilot 系列逾 1.5 億；逾九成財星 500 大企業使用 M365 Copilot，PwC 單季增加 15.5 萬席位。M365 商業雲年增 17%，ARPU 由 E5 與 Copilot 帶動，付費席位年增 6%。生產力部門營益率年增 3pp 到 62%，AI 投入被效率提升抵銷。</p>
</div>

<div class="sb">
<h3>🎯 洞察五：資本支出 349 億，半數是短年限設備</h3>
<p>Hood 說約一半資本支出用於 GPU、CPU 等短年限資產，其餘為可貨幣化 15 年以上的長年限資產，含 111 億融資租賃。隨需求加速與 RPO 成長，<b>「我們正在增加 GPU 與 CPU 的支出」</b>，Q2 資本支出將季增，FY26 增速將高於 FY25。毛利率年減 0.3pp 到 69%，Q2 雲端毛利率將降到約 66%。</p>
</div>

## 3. 🛡️ 護城河與 Q2 財測展望

<div class="sb">
<h3>🏰 核心護城河：可替換用途的算力機隊加上企業軟體</h3>
<p>Nadella 強調機隊「可替換用途」，可在預訓練、後訓練、推論與資料庫等工作負載間調度，本季 GPT-4.1 與 GPT-5 的每顆 GPU 吞吐量提升逾 30%。Azure AI Foundry 有 8 萬家客戶、逾 1.1 萬個模型，GitHub 有 1.8 億開發者，企業從 Office 到資安都在同一平台，轉換成本高。</p>
</div>

## 4. ⚠️ 風險提示

<h3 class="risk-red">🔴 高風險（High Risk）</h3>
<div class="sb rh"><ul>
<li><b>資本支出持續攀升</b>：Q1 含租賃 349 億，Q2 將再增加，FY26 增速高於 FY25，折舊將壓抑毛利率。</li>
<li><b>OpenAI 集中度</b>：新簽約翻倍主要來自 OpenAI，單一客戶承諾讓 RPO 與簽約大幅波動。</li>
</ul></div>

<h3 class="risk-gold">🟡 中風險（Medium Risk）</h3>
<div class="sb rm"><ul>
<li><b>產能受限</b>：Azure 至少到財年底產能吃緊，Q2 財測降到約 37%。</li>
<li><b>OpenAI 投資損益波動</b>：OpenAI 轉為公益公司後，投資損益波動加大，GAAP EPS 本季已少 0.41 美元。</li>
<li><b>PC 需求前移</b>：Windows 10 停更帶動的 OEM 需求與偏高庫存，Q2 起將回落。</li>
</ul></div>

<h3 class="risk-green">🟢 低風險／潛在機會（Low Risk / Opportunity）</h3>
<div class="sb rl"><ul>
<li><b>2,500 億 Azure 追加承諾</b>：尚未計入 Q1 RPO，下季簽約與 RPO 將明顯增加。</li>
<li><b>營業槓桿</b>：營業費用只增 5%，營益率升到 48.9%。</li>
</ul></div>

## 6. 📋 關鍵觀察

- **Azure 超預估**：年增 40%、高於財測，但產能吃緊到財年底，Q2 財測約 37%。
- **獲利結構好**：營收 777 億（+18%）、營益率 48.9%，排除 OpenAI 的 EPS 4.13 美元（+23%）。
- **訂單大增**：新簽約 +112%、RPO 3,920 億，還沒計入 OpenAI 追加的 2,500 億。
- **資本支出加速**：含租賃 349 億，Q2 再增，FY26 增速高於 FY25。
- **OpenAI 雙面**：帶來大單，也讓 GAAP EPS 少 0.41 美元並推高客戶集中度。

> 💡 **一句話總結**：Microsoft 用 40% 的 Azure 成長與 3,920 億 RPO 開啟 FY26，但產能受限與加速的資本支出，讓接下來幾季的重點變成「能多快把產能變成營收」。
