## 2. 🔍 五大核心洞察與法說會直擊

<div class="sb">
<h3>🎯 洞察一：Azure 在缺產能下仍加速到 48%</h3>
<p>Azure 營收 332 億、年增 48%，Q2 財測再升到 49–50%。財務長 Amy Hood 說：<b>「Azure 營收優於預期，年增 48%，即使有第三方產能延遲」</b>。加速來自 Foundry 營收年增逾 3 倍、閒置 CPU 被找出來變現，以及<b>「本季的 token 價格高於預期」</b>。她也提醒，客戶需求仍超過可用供給，效率提升與新產能上線的時點會讓季度成長率波動。</p>
</div>

<div class="sb">
<h3>🎯 洞察二：曆年資本支出約 1,700 億，首度提到對外籌資</h3>
<p>Q1 資本支出 452 億，部分第三方產能交付延到下半財年。Hood 預告 Q2 將超過 500 億，2026 曆年約 1,700 億，下半財年再加速。自由現金流 186 億、年減 27%。她說 FY27 自由現金流仍會為正，但<b>「在我們認為有利時，會取用額外的資金來源」</b>，等於表態可能舉債或另闢財源。業外收支也要承擔資料中心融資租賃的利息。</p>
</div>

<div class="sb">
<h3>🎯 洞察三：RPO 6,770 億、年增 73%，新簽約金額卻年減 12%</h3>
<p>商業剩餘履約義務（RPO）6,770 億，加權平均期間 2.3 年，約 30% 在未來 12 個月認列、年增 29%，12 個月以後的部分年增 98%。商業新簽約金額年減 12%，Hood 解釋是去年同期有大型 Azure 承諾墊高基期，本季也簽下一筆大型 Azure 承諾。大額合約會讓簽約金額大幅波動，看 RPO 比看單季簽約更有意義。</p>
</div>

<div class="sb">
<h3>🎯 洞察四：Copilot 走向用量計費，大型部署倍增</h3>
<p>執行長 Satya Nadella 說：<b>「擁有逾 5 萬個 Copilot 席位的客戶數年增逾 8 倍」</b>，福斯汽車計畫部署給逾 33 萬名員工。採用量計費的 Copilot 客戶季增逾 75%，GitHub 上超過三分之一的 PR 由 AI 代理開出。代理程式登記數逾 5,000 萬、季增逾 30%。弱點在 M365 E3 與單品銷售執行偏弱，付費商業席位只增 5%，成長主要靠每用戶營收。</p>
</div>

<div class="sb">
<h3>🎯 洞察五：PC 拖累消費端，雲端毛利率續降</h3>
<p>Windows OEM 營收年減 27%，原因是去年 Windows 10 停止支援的換機潮墊高基期、通路去化庫存與 PC 需求轉弱，Hood 說庫存仍偏高，Q2「Windows OEM 與裝置」營收將年減約 35%。Microsoft Cloud 毛利率 66%，Q2 預估約 65%，因為 Azure 比重上升。Q2 成本財測含自願離職方案的估計費用，營業利益率預計年減少許。</p>
</div>

## 3. 🛡️ 護城河與 Q2 財測展望

<div class="sb">
<h3>🏰 核心護城河：一池可互換的算力，加上 Copilot 到資料庫的整套產品</h3>
<p>Nadella 說微軟把資料中心當成<b>「一個池子」</b>，GPU、CPU 與儲存可在 Azure、Foundry、Copilot 之間調配給價值最高的需求；本季 GB300 從到貨到上線時間季減約 20%。自研 Maia 200 在 Teams 與 Copilot 每瓦 token 數最高提升 1.7 倍。企業客戶從 Copilot、Foundry、資料庫到 Agent 365 治理都在同一平台，轉換成本高。</p>
</div>

## 4. ⚠️ 風險提示

<h3 class="risk-red">🔴 高風險（High Risk）</h3>
<div class="sb rh"><ul>
<li><b>資本支出吃掉現金流</b>：曆年資本支出約 1,700 億、Q2 逾 500 億，自由現金流已年減 27%，公司表態可能對外籌資。</li>
<li><b>折舊壓力</b>：四分之三資本支出是短年限 GPU、CPU，折舊攤銷年增 44%，未來幾年將持續壓低毛利率。</li>
</ul></div>

<h3 class="risk-gold">🟡 中風險（Medium Risk）</h3>
<div class="sb rm"><ul>
<li><b>第三方產能延遲</b>：部分 GPU 即服務合約延到下半財年，交付再延會直接影響 Azure 財測。</li>
<li><b>席位成長放緩</b>：付費 M365 商業席位只增 5%、E3 銷售偏弱，成長越來越依賴 Copilot 與漲價。</li>
<li><b>PC 需求疲弱</b>：Windows OEM 與裝置營收 Q2 預估年減約 35%，通路庫存仍高。</li>
</ul></div>

<h3 class="risk-green">🟢 低風險／潛在機會（Low Risk / Opportunity）</h3>
<div class="sb rl"><ul>
<li><b>Token 價格與效率</b>：高品質模型帶來較高 token 價格，GPU 效率提升可把更多產能轉給 Foundry。</li>
<li><b>RPO 可見度</b>：6,770 億 RPO 中約 30% 在 12 個月內認列，支撐未來一年營收。</li>
</ul></div>

## 6. 📋 關鍵觀察

- **Azure 加速**：Azure 332 億（+48%），Q2 財測 49–50%，Foundry 營收年增逾 3 倍。
- **獲利仍強**：營收 923 億（+19%）、營益率 49.8%，排除 OpenAI 的 EPS 4.89 美元（+18%）。
- **資本支出再升**：Q1 452 億、Q2 逾 500 億、曆年約 1,700 億，自由現金流年減 27%。
- **訂單可見度高**：RPO 6,770 億（+73%），約 30% 在 12 個月內認列。
- **消費端拖累**：Windows OEM -27%、Q2 約 -35%，雲端毛利率由 66% 降到約 65%。

> 💡 **一句話總結**：Microsoft 用更高的資本支出換到 Azure 加速與 50% 營益率，但自由現金流已開始下滑；下一步要看 1,700 億的建置能否在毛利率不再明顯下滑的情況下轉成營收。
